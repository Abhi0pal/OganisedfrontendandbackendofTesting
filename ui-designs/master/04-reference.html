⚙ Yeh kaise kaam karta hai — Backend Logic
On Data Save
1. Data row save hoti hai master_data mein
2. Backend JSONB data mein SELECT columns scan karta hai
3. Jo column ka options.source = "MASTER" ho, us value ke liye master_data_reference mein ek record INSERT karta hai
4. UNIQUE constraint duplicate prevent karta hai
On Cascading Dropdown
User state = "Uttarakhand" (id=5) select karta hai →
SELECT from_data_id
FROM master_data_reference
WHERE to_data_id = 5
AND column_key = 'state_id' → Sirf Uttarakhand ke districts milenge dropdown mein
